How to start a Quran journal

  1. Read a verse or a short passage. Note its surah and ayah number so you can find it again.
  2. Choose one prompt. Write a sentence about what you noticed and how it connects to your day.
  3. Keep the reflection. Copy it into a notes app or print it to keep on paper. Read it again when you return to that passage.

Can I use this template on paper?

Yes. Choose “Print blank template” for a page with space for the date, ayah reference and reflection. In the print dialog you can also save it as a PDF.

What if I don’t know the ayah number?

Leave the reference blank or write the surah name. You can look up the ayah number later.
